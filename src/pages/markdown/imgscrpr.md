## Overview

Imgscrpr is a Discord bot that builds a personalized Reddit feed using a subreddit-relationship graph. It delivers curated media directly inside Discord.

## Problem

Reddit content discovery is noisy, and Discord communities want targeted media feeds without endless scrolling. Users needed a way to surface relevant content quickly.

## Approach

- Modeled subreddit relationships to learn affinity between topics.
- Implemented the bot with TypeScript, Node.js, and MongoDB for fast queries and caching.
- Delivered results in a Discord-native format for quick sharing.

## Outcome

Imgscrpr created a lightweight and personalized content pipeline that made discovery feel immediate for Discord communities.
